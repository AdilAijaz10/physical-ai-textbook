# Hardware Requirements

## Minimum System Requirements

For the practical exercises in this course, the following minimum specifications are required:

- **CPU**: Intel i7 or AMD Ryzen 7 with 8+ cores
- **RAM**: 16GB minimum
- **GPU**: NVIDIA RTX 3060 or equivalent with CUDA support
- **Storage**: 500GB SSD minimum
- **OS**: Ubuntu 20.04 LTS or Windows 10/11 with WSL2

## Recommended Hardware for Advanced Work

For optimal performance during complex simulations and advanced work:

- **CPU**: Intel i9 or AMD Ryzen 9 with 16+ cores
- **RAM**: 64GB or more
- **GPU**: NVIDIA RTX 4080 or A6000 for advanced simulation
- **Additional**: Multiple monitors for development

## Software Prerequisites

Before starting the course, ensure you have the following software installed:

- ROS 2 Humble Hawksbill or later
- Gazebo Garden or Fortress
- Unity 2022.3 LTS or later
- NVIDIA Isaac ROS packages
- Python 3.8+ with required libraries
- Git version control
- Docker for containerized environments

## Setup Instructions

### Ubuntu 20.04 LTS Setup

1. Update your system:
   ```bash
   sudo apt update && sudo apt upgrade
   ```

2. Install Python dependencies:
   ```bash
   sudo apt install python3-pip python3-dev
   ```

3. Install additional development tools:
   ```bash
   sudo apt install build-essential cmake git
   ```

### Windows with WSL2 Setup

1. Install WSL2 with Ubuntu 20.04
2. Follow the Ubuntu setup instructions within WSL2
3. Install X-server for GUI applications if needed

## Physical Robot Options (Optional)

- **Research Platforms**: NAO, Pepper, or custom humanoid platforms
- **Simulation Focus**: High-end gaming PC for complex simulations

## Troubleshooting

If you encounter hardware compatibility issues:

1. Check the official documentation for your specific hardware
2. Verify that your GPU supports the required frameworks
3. Ensure sufficient disk space for simulation environments
