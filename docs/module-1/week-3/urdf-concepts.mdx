# Week 3: URDF for Humanoid Robots

## Learning Objectives

- Understand URDF structure and components
- Create humanoid robot models
- Configure joint constraints and physical properties

## Overview

This week introduces the Unified Robot Description Format (URDF) and its application to humanoid robots. We'll learn how to describe robot models in XML format.

## URDF Structure

URDF is an XML format for representing a robot model. It describes the robot's physical and visual properties, including links, joints, and materials.
