# Introduction to Physical AI & Humanoid Robotics

Welcome to the comprehensive textbook on Physical AI & Humanoid Robotics. This course is designed to take you from fundamental concepts to advanced implementations in humanoid robotics, covering ROS 2, simulation environments, AI integration, and vision-language-action systems.

## Course Overview

This 13-week curriculum is organized into 4 main modules:

1. **Module 1: The Robotic Nervous System (ROS 2)** - Learn ROS 2 architecture, nodes, topics, services, Python integration, and URDF for humanoid robots
2. **Module 2: The Digital Twin (Gazebo & Unity)** - Explore physics simulation in Gazebo, high-fidelity rendering in Unity, and sensor simulation
3. **Module 3: The AI-Robot Brain (NVIDIA Isaac)** - Work with Isaac Sim, Isaac ROS for VSLAM and navigation, and Nav2 for bipedal movement
4. **Module 4: Vision-Language-Action (VLA)** - Implement voice commands with OpenAI Whisper, LLM cognitive planning, and complete a capstone autonomous humanoid project

## Learning Objectives

By the end of this course, you will be able to:
- Design and implement ROS 2-based robotic systems for humanoid robots
- Create and simulate humanoid robots using Gazebo and Unity
- Integrate NVIDIA Isaac tools for AI-powered robotic behaviors
- Implement Vision-Language-Action systems for autonomous humanoid operation
- Deploy cognitive planning systems for complex robotic tasks

## Prerequisites

- Basic programming knowledge (Python preferred)
- Understanding of linear algebra and calculus
- Basic knowledge of robotics concepts
- Familiarity with Linux command line

## Hardware Requirements

For the practical exercises in this course, you will need:
- **Minimum:** Intel i7 or AMD Ryzen 7 with 8+ cores, 16GB RAM, NVIDIA RTX 3060 or equivalent
- **Recommended:** Intel i9 or AMD Ryzen 9 with 16+ cores, 32GB+ RAM, NVIDIA RTX 4080 or A6000
