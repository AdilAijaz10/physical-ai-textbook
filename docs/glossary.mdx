# Glossary of Terms

This glossary contains definitions of technical terms used throughout the Physical AI & Humanoid Robotics textbook.

## A

**Action**: A communication pattern in ROS 2 for long-running tasks with feedback and the ability to cancel.

## C

**Computer Vision**: A field of artificial intelligence that trains computers to interpret and understand the visual world.

## D

**Deep Learning**: A subset of machine learning that uses neural networks with many layers.

## G

**Gazebo**: A physics-based 3D simulator for robotics applications.

## I

**Isaac Sim**: NVIDIA's robotics simulator for developing and testing AI-based robotics applications.

## L

**LiDAR**: Light Detection and Ranging - a remote sensing method that uses light in the form of a pulsed laser to measure distances.

## M

**Machine Learning**: A method of data analysis that automates analytical model building.

## N

**Navigation 2 (Nav2)**: The ROS 2 navigation stack for path planning and obstacle avoidance.

## R

**Robot Operating System (ROS)**: A flexible framework for writing robot software.

**ROS 2**: The next generation of Robot Operating System with improved security, scalability, and real-time capabilities.

## S

**SLAM**: Simultaneous Localization and Mapping - the computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.

**Service**: A communication pattern in ROS 2 for synchronous request/response interactions.

## T

**Topic**: A named bus over which ROS 2 nodes exchange messages in a publish-subscribe model.

## U

**URDF**: Unified Robot Description Format - an XML format for representing a robot model.

## V

**VSLAM**: Visual Simultaneous Localization and Mapping - using visual sensors for SLAM.

**Vision-Language-Action (VLA)**: Systems that integrate visual perception, language understanding, and physical action capabilities.

## W

**Whisper**: OpenAI's automatic speech recognition system.
